# 个人网站每日学习复习笔记

这个目录用于保存个人网站项目每天的学习总结。每完成一天，就新增一份对应的复习文档，方便以后按天回顾，而不需要重新翻找聊天记录。

## 使用方法

建议每次学习按下面的顺序进行：

```text
开始当天学习
↓
理解概念并动手编写代码
↓
完成当天验收
↓
补充当天复习文档
↓
第二天开始前快速复习
```

复习时不要只看答案。可以先尝试回答文档里的“自测题”，再查看前面的知识说明。

## 每日文档固定结构

以后每天的复习文档尽量包含：

1. 今天完成了什么；
2. 必须理解的核心概念；
3. 代码与目录之间的关系；
4. 常见错误；
5. 自测题；
6. 当天验收清单；
7. 一句话总结。
